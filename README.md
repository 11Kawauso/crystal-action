# 結晶のアクション（試作版）

ブラウザで遊べる2Dドット絵アクションゲームの試作版です。

▶ **遊ぶ: https://11kawauso.github.io/crystal-action/**

パソコンのブラウザ（Chrome / Edge / Safari / Firefox）で遊べます。ゲーム画面をクリックしてから操作してください。

**第1面「結晶の谷」**: 奈落の谷・すり抜け床の塔・敵の巣・転移クリスタル（撃つとそこへ瞬間移動）を越えて、ゴールの巨大クリスタルを壊そう。

## 操作
- 移動: A / D（← →）
- ジャンプ: Space（空中でもう1回）
- ダッシュ: Shift / L
- 近接攻撃: J / 左クリック（連打で3段・ダッシュ中ならダッシュ斬り）
- 狙い撃ち: K 長押し＋WASD、または 右クリック長押し＋マウス（離すと発射。ためるほど強く、100%でビーム）
- すり抜け床から降りる: ↓＋Space
- スキルツリー: Tab
- チェックポイントからやり直し: R
- ゲームパッドにも対応
